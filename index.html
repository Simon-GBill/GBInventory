Inventaire tournant

La feuille d'inventaire, sur le téléphone. Un tap quand c'est bon, un chiffre seulement quand il y a un écart.

Reprendre

📱 Sur le téléphone

  1. Sur le PC, ouvre la page Imprimer inventaire dans jaja.
  2. Clique sur le favori 📱 Inventaire : un QR code s'affiche.
  3. Scanne-le avec l'appareil photo du téléphone.

💻 Installer le favori sur le PC

À faire une seule fois, dans Firefox sur le PC de la boutique :

  1. Affiche la barre personnelle avec Ctrl+Maj+B.
  2. Glisse ce bouton dedans :

📱 Inventaire

Ne clique pas dessus ici : il ne fonctionne que sur la page d'inventaire de jaja.

Le favori ne fait rien quand je clique dessus ?

Remplace-le par cette version autonome (même principe, elle n'a pas besoin de télécharger quoi que ce soit) :

📱 Inventaire

Les données d'inventaire restent sur ton téléphone : la liste voyage dans le QR code et la progression est enregistrée dans le navigateur, rien n'est envoyé sur internet.
